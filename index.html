🔵 Google Drive (OAuth2 API)

Sign in with Google and backup directly to your Drive using the official API. Uses scope drive.file (only files created by this app).

Create at Google Cloud Console → APIs & Services → Credentials → OAuth 2.0 Client ID (Web application). Add this page origin to Authorized JavaScript origins.
Status: Not signed in
How to create OAuth Client ID (2 minutes)
  1. Go to Google Cloud Console
  2. Create/select a project → enable Google Drive API
  3. APIs & Services → OAuth consent screen → External → fill app name, your email → Save
  4. Credentials → Create credentials → OAuth client ID → Application type: Web application
  5. Authorized JavaScript origins: add http://localhost and http://127.0.0.1 and the origin you open ARRONE from (e.g. file:// may not work — serve via local server or host the HTML)
  6. Copy the Client ID → paste above → Save Client ID → Sign in

Note: Opening via file:// often blocks OAuth. Use a local server, e.g. npx serve or Live Server, then add that origin (e.g. http://127.0.0.1:5500).
